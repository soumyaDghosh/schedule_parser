# Schedule Parser

A Dart package for scraping and parsing XML schedules generated by [Frab](https://frab.github.io/frab/), a conference management system. This package provides a command-line application and library code to extract and process schedule data from Frab-generated XML files.

## Features

- Parse Frab-generated XML schedule files.
- Extract key schedule details such as sessions, speakers, times, and locations.
- Extensible library code for custom parsing needs.
- Unit tests included for reliability and maintainability.

## Installation

Since this package is not yet published on [pub.dev](https://pub.dev), you can include it in your Dart project by referencing the GitHub repository directly.

Add the following to your `pubspec.yaml`:

```yaml
dependencies:
  schedule_parser:
    git:
      url: https://github.com/soumyaDghosh/schedule_parser.git
```

Then, run:

```bash
dart pub get
```

## Usage

### Command-Line Application

The package includes a command-line application located in the `bin/` directory. You can run it to parse a Frab-generated XML schedule file.

Example:

```bash
dart run bin/schedule_parser.dart -i <url to the xml schedule>
```

This will process the specified XML file and output the parsed schedule data. For example, it might display:

```
    Event: Keynote Address (Start: 09:00, Duration: 01:00)
    Event: Workshop: Intro to Dart (Start: 10:30, Duration: 02:00)
    Event: Panel Discussion (Start: 13:00, Duration: 01:30)
    Event: Lightning Talks (Start: 15:00, Duration: 01:00)
    Event: Closing Remarks (Start: 16:30, Duration: 00:30)
```

To limit the output to the first 5 events, the command-line application uses the `take(5)` method internally. Check the command-line help for additional options:

```bash
dart run bin/schedule_parser.dart --help
```

### Library Usage

You can use the library code in `lib/` to integrate schedule parsing into your Dart application.

Example:

```dart
import 'package:schedule_parser/schedule_parser.dart';

void main() {
  final parser = ScheduleParser();
  final xmlFilePath = 'path/to/schedule.xml';
  final schedule = parser.parse(xmlFilePath);

  print('Parsed Schedule:');
  for (var event in schedule.events.take(5)) {
    print('    Event: ${event.title} (Start: ${event.start}, Duration: ${event.duration})');
  }
}
```

For detailed API documentation, refer to the source code in the `lib/` directory.

## Project Structure

- `bin/`: Contains the command-line application entrypoint (`schedule_parser.dart`).
- `lib/`: Contains the core library code for parsing Frab XML schedules.
- `test/`: Contains unit tests to ensure the package works as expected.

## Running Tests

To run the unit tests included in the `test/` directory, use the following command:


This will execute all tests and provide a report on their status.
